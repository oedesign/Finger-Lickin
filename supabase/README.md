# Supabase workspace

Supabase is the planned PostgreSQL, Auth, and Storage platform. No CLI
configuration, project link, migration, seed, or database policy is created
in the application foundation.

Install the Supabase CLI using its official installation guidance before
running `supabase init` and `supabase start`. Review generated configuration
before use. Never link this phase to a production project.

- `migrations/` is reserved for reviewed database changes.
- `tests/` is reserved for database integrity and row-level-security tests.
